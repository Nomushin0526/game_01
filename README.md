# ゲームコレクション

スマホのブラウザで遊ぶミニゲーム集です。ビルド不要で、素の HTML / CSS / JavaScript だけで作っています。

## 方針

- **スマホ・縦画面・片手（親指）操作が前提**。PCでは画面中央に縦長の枠で表示される（動作確認用）
- 操作はタッチ（なぞる・タップ）が基本。キーボードはPCでの確認用
- スマホを横にすると「縦向きにしてね」と表示して一時停止する

## 遊び方（ローカル）

`index.html` をブラウザで開くだけで動きます。
スマホで試す場合や、うまく動かない場合は簡易サーバーを立ててください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## フォルダ構成

```
index.html          ゲーム一覧（トップページ）
shared/             全ゲーム共通の部品
  ui.css            色・フォント・ボタンなど共通デザイン
  ui.css の .app    縦画面のゲーム枠（スマホは全画面、PCは中央に縦長表示）
  input.js          タッチ入力（指でなぞる量・左右タッチ）+ PC確認用キーボード
  haptics.js        スマホの振動（Android のみ。iPhone の Safari は非対応）
  audio.js          効果音（Web Audio、音源ファイル不要）
  storage.js        ハイスコア等の保存
  vendor/three.min.js  3D描画ライブラリ Three.js r149（MITライセンス、three.LICENSE）
games/
  cart-rush/        カートラッシュ！
```

新しいゲームは `games/<ゲーム名>/` にフォルダを作り、トップの `index.html` にカードを1枚追加します。

## カートラッシュ！

ショッピングカートを押す主婦が、スーパーから家まで爆走する3Dランゲーム（Three.js / WebGL）。

| ファイル | 役割 |
| --- | --- |
| `stages.js` | ステージ定義（長さ・チェックポイント・区間）、速度、ジャンプ台、操作の感度 |
| `models.js` | 3Dモデルとテクスチャ（主人公、買い物客、車、障害物、商品棚の絵など） |
| `render3d.js` | 3D描画（Three.js）。カメラ、景色の自動生成、障害物の表示 |
| `game.js` | ゲーム進行（障害物の出現、当たり判定、タイマー、HP、結果画面） |

舞台は東京の下町〜湾岸（実在の地名をモデルにしたコース）。

- **ステージ1 下町のスーパー**（★）: 青果 → 精肉・鮮魚 → 日用品 → お菓子コーナーを抜けてレジへ
- **ステージ2 下町の帰り道**（★★ 浅草 → 月島）: 商店街のアーケード → 江戸通り → 隅田川の橋 → 清澄通り。車はウィンカーを出して車線変更
- **ステージ3 湾岸ハイウェイ**（★★★ 月島 → 葛西）: 晴海通り → 首都高 湾岸線 → 葛西。車はウィンカーなしで割り込む
- **昼と夜**: ステージ選択で切り替え（記録は別々）

### 操作と動き
- 指を置いて左右にスライド：移動 / 上にはらう：ジャンプ / 下にはらう：スライディング（空中なら急降下）
- PC: ←→ 移動、↑・スペース ジャンプ、↓ スライディング、E タイムセール
- のれん・吊り下げ幕はスライディングでくぐる。工事のバーはジャンプかスライディング
- 車の屋根に降りるとポンと弾む（車から車へ渡れる）
- 大通りは歩道まで出られる: 車は来ないが最高速度が72%に落ち（歩道ばかりだと時間に間に合わない）、イチョウ並木・街灯・自販機・ポスト・ベンチをよけて走る抜け道。段差をまたぐとガタンと揺れる。歩道の物ではゲージはたまらない
- 加速ジャンプ台: 坂を登りきると大ジャンプ＆加速、空中で回転技。空中で次の台に乗ると連続ジャンプ（最大3段階）。トラック・バスの後ろの台は屋根の高さから飛び出す
- ぶつかると転倒してスローモーション

### 障害物の流れ（緩急）
1行ずつランダムに置くのではなく、場面のパターンを交互に出す（`game.js` の `PATTERNS`）
- ラッシュ: 障害物が詰まったスラローム。最後にジャンプ台
- ジャンプ台ゾーン: 2〜3段の連続ジャンプ台。飛んでいる下に障害物
- ぶっ飛ばしゾーン: はね飛ばせる物がずらり（ゲージがたまる）
- 関門: 道幅いっぱいのバー・のれん（ジャンプかスライディング）
- 休憩: ひと息。最後にジャンプ台

### BGM
音源ファイルなしで鳴らす簡易BGM（`shared/audio.js` の `playMusic`）。ステージごとに曲調が変わり、タイムセール中はにぎやかになる

### セールゲージとタイムセール
- ジャンプする・コーンや立て看板をはね飛ばす・空中で技を決める・ギリギリで避ける・屋根で弾む とたまる
- 満タンで右下の「タイムセール！」ボタン（設定で自動発動も可）: 6秒間 無敵＋超加速、ぶつかった物を全部はね飛ばす

### モードとその他
- **チェックポイントモード**: 制限時間 + HP3。チェックポイントで時間追加＋HP回復。ぶつかると -0.5秒
- **タイムアタック**: ぶつかるたびに +3秒。最速タイムを記録。自己ベストの走りが水色のゴーストになって一緒に走る（ステージ・昼夜ごと）
- **制限時間**: 各区間を「ミスなし・ジャンプ台なし」で走った最短タイム + `slack` 秒（ステージ1は3秒、2・3は1.5秒）
- **設定**: カメラ視点（標準 / 見下ろし / 一人称）、タイムセールの発動（ボタン / 自動）
- **結果画像のシェア**: ゴールの瞬間の画面とスコアを1枚の画像にして保存・シェア
- プレイ中の表示は最小限: 残り時間（タイムアタックは経過タイム）・ハート・セールゲージ・一時停止だけ。スコアや距離は結果画面で見せる。拾うアイテムはなし（避けることに集中）

難易度の調整は `stages.js` の `slack`（時間の余裕）・`hitPenalty`・`laneChange`（車線変更の頻度・ウィンカー有無）・`CartMove`（ジャンプ・スライディング）・`CartSale`（ゲージ）と、
`stages.js` の `CartThemes`（速度）・`CartJump`（ジャンプ台）・`CartControl`（操作の感度）、`game.js` の `spawnRow`（障害物の密度）で行えます。
