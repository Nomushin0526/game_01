# ゲームコレクション

スマホのブラウザで遊ぶミニゲーム集です。ビルド不要で、素の HTML / CSS / JavaScript だけで作っています。

## 方針

- **スマホ・縦画面・片手（親指）操作が前提**。PCでは画面中央に縦長の枠で表示される（動作確認用）
- 操作はタッチ（なぞる・タップ）が基本。キーボードはPCでの確認用
- スマホを横にすると「縦向きにしてね」と表示して一時停止する

## 遊び方（ローカル）

`index.html` をブラウザで開くだけで動きます。
スマホで試す場合や、うまく動かない場合は簡易サーバーを立ててください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## フォルダ構成

```
index.html          トップ（開くとすぐカートラッシュへ移動）
games/index.html    ゲーム一覧
shared/             全ゲーム共通の部品
  ui.css            色・フォント・ボタンなど共通デザイン
  ui.css の .app    縦画面のゲーム枠（スマホは全画面、PCは中央に縦長表示）
  input.js          タッチ入力（指でなぞる量・左右タッチ）+ PC確認用キーボード
  haptics.js        スマホの振動（Android のみ。iPhone の Safari は非対応）
  audio.js          効果音（Web Audio、音源ファイル不要）
  storage.js        ハイスコア等の保存
  vendor/three.min.js  3D描画ライブラリ Three.js r149（MITライセンス、three.LICENSE）
games/
  cart-rush/        カートラッシュ！
  fu-rising/        成り上がれ！歩兵（将棋×経済）
  kotodama/         言霊デュエル（ことばカードバトル）
  shaso-run/        車窓ラン（横画面・試作）
  bat-craft/        バット職人
```

新しいゲームは `games/<ゲーム名>/` にフォルダを作り、`games/index.html`（ゲーム一覧）にカードを1枚追加します。

## カートラッシュ！

ショッピングカートを押す主婦が、スーパーから家まで爆走する3Dランゲーム（Three.js / WebGL）。

| ファイル | 役割 |
| --- | --- |
| `stages.js` | ステージ定義（長さ・チェックポイント・区間）、速度、ジャンプ台、操作の感度 |
| `models.js` | 3Dモデルとテクスチャ（主人公、買い物客、車、障害物、商品棚の絵など） |
| `render3d.js` | 3D描画（Three.js）。カメラ、景色の自動生成、障害物の表示 |
| `game.js` | ゲーム進行（障害物の出現、当たり判定、タイマー、HP、結果画面） |

舞台は東京の下町〜湾岸（実在の地名をモデルにしたコース）。

- **ステージ1 下町のスーパー**（★）: 青果 → 精肉・鮮魚 → 日用品 → お菓子コーナーを抜けてレジへ
- **ステージ2 下町の帰り道**（★★ 浅草 → 月島）: 商店街のアーケード → 江戸通り → 隅田川の橋 → 清澄通り。車はウィンカーを出して車線変更
- **ステージ3 湾岸ハイウェイ**（★★★ 月島 → 葛西）: 晴海通り → 首都高 湾岸線 → 葛西。車はウィンカーなしで割り込む
- **昼と夜**: ステージ選択で切り替え（記録は別々）

### 操作と動き
- 指を置いて左右にスライド：移動 / 上にはらう：ジャンプ / 下にはらう：スライディング（空中なら急降下）
- PC: ←→ 移動、↑・スペース ジャンプ、↓ スライディング、E タイムセール
- のれん・吊り下げ幕はスライディングでくぐる。工事のバーはジャンプかスライディング
- 車の屋根に降りるとポンと弾む（車から車へ渡れる）
- 大通りは歩道まで出られる: 車は来ないが最高速度が72%に落ち（歩道ばかりだと時間に間に合わない）、イチョウ並木・街灯・自販機・ポスト・ベンチをよけて走る抜け道。段差をまたぐとガタンと揺れる。歩道の物ではゲージはたまらない
- 加速ジャンプ台: 坂を登りきると大ジャンプ＆加速、空中で回転技。空中で次の台に乗ると連続ジャンプ（最大3段階）。トラック・バスの後ろの台は屋根の高さから飛び出す
- ぶつかると転倒してスローモーション。ぶつかった相手は大きくはね飛ばされてポンと消える
- ぶつかるたびにカートが壊れていく（カゴがゆがむ → 車輪が外れる → 取っ手が曲がる → 食材が落ちる。ボロボロだと煙を引く）。チェックポイントでHPが戻ると少し直る
- 関門（バー・のれん）は道幅いっぱいにはならず、必ずどこか1車線は空いている

### 障害物の流れ（緩急）
1行ずつランダムに置くのではなく、場面のパターンを交互に出す（`game.js` の `PATTERNS`）
- ラッシュ: 障害物が詰まったスラローム。最後にジャンプ台
- ジャンプ台ゾーン: 2〜3段の連続ジャンプ台。飛んでいる下に障害物
- ぶっ飛ばしゾーン: はね飛ばせる物がずらり（ゲージがたまる）
- 関門: 道幅いっぱいのバー・のれん（ジャンプかスライディング）
- 休憩: ひと息。最後にジャンプ台

### BGM
音源ファイルなしで鳴らす簡易BGM（`shared/audio.js` の `playMusic`）。ステージごとに曲調が変わり、タイムセール中はにぎやかになる

### セールゲージとタイムセール
- ジャンプする・コーンや立て看板をはね飛ばす・空中で技を決める・ギリギリで避ける・屋根で弾む とたまる
- 満タンで右下の「タイムセール！」ボタン（設定で自動発動も可）: 6秒間 無敵＋超加速、ぶつかった物を全部はね飛ばす

### モードとその他
- **チェックポイントモード**: 制限時間 + HP3。チェックポイントで時間追加＋HP回復。ぶつかると -0.5秒
- **タイムアタック**: ぶつかるたびに +3秒。最速タイムを記録。自己ベストの走りが水色のゴーストになって一緒に走る（ステージ・昼夜ごと）
- **制限時間**: 各区間を「ミスなし・ジャンプ台なし」で走った最短タイム + `slack` 秒（ステージ1は3秒、2・3は1.5秒）
- **設定**: カメラ視点（標準 / 見下ろし / 一人称）、タイムセールの発動（ボタン / 自動）
- **結果は被害額だけ**（寿司打のようにシンプルに）: ぶつかった・はね飛ばした物の弁償代の合計と、金額に応じたひと言（「無事故！ご近所の鑑」〜「伝説の主婦」）。チェックポイントモードの記録は「クリアしたときの最少被害額」
- **結果画像のシェア**: ゴールの瞬間の画面とスコアを1枚の画像にして保存・シェア
- プレイ中の表示は最小限: 残り時間（タイムアタックは経過タイム）・ハート・セールゲージ・一時停止だけ。スコアや距離は結果画面で見せる。拾うアイテムはなし（避けることに集中）

難易度の調整は `stages.js` の `slack`（時間の余裕）・`hitPenalty`・`laneChange`（車線変更の頻度・ウィンカー有無）・`CartMove`（ジャンプ・スライディング）・`CartSale`（ゲージ）と、
`stages.js` の `CartThemes`（速度）・`CartJump`（ジャンプ台）・`CartControl`（操作の感度）、`game.js` の `spawnRow`（障害物の密度）で行えます。

## 成り上がれ！歩兵

盤には王と歩だけ。お金と合成で「最強の歩」を育てて、相手の王を詰ませる将棋ゲーム（対コンピューター）。

| ファイル | 役割 |
| --- | --- |
| `rules.js` | 盤・駒の動き（歩＋強化＋合成した駒の動きの合計）・合法手・詰み判定 |
| `economy.js` | お金・ショップ（買うたびに品ぞろえが変わる）・金銀相場 |
| `ai.js` | 相手の思考（2手読み）と、お金・相場の使い方 |
| `game.js` | 画面と進行 |

- 1手番: ショップ・相場・強化・合成は何回でも（相場の売買は3回まで）→ 最後に駒を1つ動かすか持ち歩を打つ
- 歩の強化: お金で「脚力アップ／横歩き／後ずさり／鉄の鎧」を付ける、または飛・角・香・桂・金・銀を合成（動きが合わさる、1枚に3つまで）
- 駒の入手: ショップで買う、相手の合成歩を取って合成されていた駒を1つ奪う
- 金銀相場: 敵味方共通。手番ごとに変動し、買うと上がり売ると下がる（手数料8%）
- 王の逆襲（1局2回）: 王のとなりの敵の歩を、守られていても鎧でもなぎ払う。CPUも使う。詰みからの脱出にも使える
- 合成すると二つ名とレア度（N〜UR）が付き、カットインが出る（`rules.js` の `epithet`）
- カオス経済（`economy.js`）: 毎手インフレ（金銀は物価連動）、ニュースで相場が最大±45%・給付金など、借金（利息毎手番10%、¥400で差し押さえ、¥800で自己破産）、12手ごとに確定申告（所持金の10%）

## 言霊デュエル

名詞に 助詞・動詞・助動詞 を重ねて文を作り、その言葉どおりの効果で戦うカードバトル（対コンピューター）。

| ファイル | 役割 |
| --- | --- |
| `cards.js` | カードの定義（名詞・動詞・助詞・助動詞・トラップ）、デッキ、文の効果の計算（`evaluate`）、活用（食べちゃう 等） |
| `ai.js` | 相手の考え方（どの名詞を出し、何を重ね、どこを攻撃するか。トラップを使うか） |
| `game.js` | 画面と進行（ターン、攻撃と守備、トラップの確認、演出） |

- HP 100（山札が切れると毎ターン10・20・30…の言葉切れダメージ）。助詞→動詞→助動詞の順に重ねる。1つの文は1ターン1回発動
- マナ（デュエマ式）: 毎ターン手札を1枚マナにでき、カードにはコストがある（`cards.js` の `NOUN_COST` 等）。助詞はコスト0
- 手札は手に持った扇形: 左右にふって選ぶ → タップで詳細 → もう一度タップで場に出す
- デッキ構築: 全カードから30枚、同じカードは3枚まで、言葉狩りは制限カード（1枚）。マイデッキは端末に保存
- 文の強さ = 名詞の強さ × 動詞との相性 × 正しい助詞（×1.5、まちがうと×0.8）× 助動詞（た・ます・まくる・ちゃう）
- 効果は 攻撃・回復・守り・バフ（自分の文を強化）・デバフ（相手の文を弱体化、眠らせる）・妨害（伏せカード破壊／手札破壊）。どのデッキにも全役割がそろう
- 動詞のない言葉は1回で消える。食べる・投げる等は使い切り、振り回す・かみつく・すすめる等は場に残る
- 攻撃は相手の場の言葉から（守備より大きいと破壊して貫通、届かないと反動）。場が空なら直接
- トラップ: 言葉狩り・る攻め・揚げ足取り・沈黙は金・聞き間違い。「ます」を付けた丁寧な文はトラップを受けない
- デッキ: 食べ物（回復＆ドロー）・武器道具・動物。CPU同士の自動対戦で勝率が4〜6割に収まるよう調整（URLに `#fast` を付けると演出を飛ばす開発用モード）

## 車窓ラン（試作）

車の窓から見える景色の上を、黒い人型が走るランゲーム。**このゲームだけ横画面**（縦にすると「横向きにしてね」）。

| ファイル | 役割 |
| --- | --- |
| `world.js` | 窓の外の景色（Three.js）。建物・ガードレール・フェンス・標識・自販機・並走車を作り、走れる足場のデータも持つ |
| `runner.js` | 黒い人型（デザインした形を、走りに合わせて動かす） |
| `game.js` | 進行（車の速さと信号、ジャンプ・着地・ぶつかり、窓枠と表示） |

- タップでジャンプ、空中でもう一度タップで2段ジャンプ。足場が切れたら落ちる
- 窓に近い物ほど速く流れる。窓の右端から出たら置いていかれてアウト。赤信号で車が止まったら追いつける
- 景色は写真を使わず、建物の窓・看板・質感をプログラムで描き、日差しの影で立体感を出している
- いまはステージ1（日本橋 → 品川、国道15号 第一京浜）だけ

## バット職人

旋盤で回る角材を削って、磨いて、ニスで仕上げる職人ゲーム（Three.js）。

| ファイル | 役割 |
| --- | --- |
| `bat.js` | 角材（削った半径・荒さ・ツヤを長さ方向に持つ）と工房・旋盤の3D、木目テクスチャ、削りくず、拡大鏡 |
| `game.js` | 4つの工程（荒削り・仕上げ削り・やすりがけ・ニス塗り）、指の操作、採点とランク |

- 削る: 回る角材の横を指でなぞる。指をバットに近づけるほど深く削れる（刃は指より内側）。点線が理想の形、削りすぎると赤
- やすり・ニス: バットの上を指でこする
- 採点: 形55%・なめらかさ25%・ツヤ20%。ランクは なし（ただの角材）→ N（バット？？）→ R（普通のバット）→ SR（磨かれたバット）→ SSR（職人のバット）→ UR（究極のバット）、ランクごとのグラデーションとひと言
