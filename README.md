# ゲームコレクション

スマホのブラウザで遊ぶミニゲーム集です。ビルド不要で、素の HTML / CSS / JavaScript だけで作っています。

## 方針

- **スマホ・縦画面・片手（親指）操作が前提**。PCでは画面中央に縦長の枠で表示される（動作確認用）
- 操作はタッチ（なぞる・タップ）が基本。キーボードはPCでの確認用
- スマホを横にすると「縦向きにしてね」と表示して一時停止する

## 遊び方（ローカル）

`index.html` をブラウザで開くだけで動きます。
スマホで試す場合や、うまく動かない場合は簡易サーバーを立ててください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## フォルダ構成

```
index.html          ゲーム一覧（トップページ）
shared/             全ゲーム共通の部品
  ui.css            色・フォント・ボタンなど共通デザイン
  ui.css の .app    縦画面のゲーム枠（スマホは全画面、PCは中央に縦長表示）
  input.js          タッチ入力（指でなぞる量・左右タッチ）+ PC確認用キーボード
  haptics.js        スマホの振動（Android のみ。iPhone の Safari は非対応）
  audio.js          効果音（Web Audio、音源ファイル不要）
  storage.js        ハイスコア等の保存
games/
  cart-rush/        カートラッシュ！
```

新しいゲームは `games/<ゲーム名>/` にフォルダを作り、トップの `index.html` にカードを1枚追加します。

## カートラッシュ！

ショッピングカートを押す主婦が、スーパーから家まで爆走する疑似3Dランゲーム。

| ファイル | 役割 |
| --- | --- |
| `stages.js` | ステージ定義（長さ・チェックポイント・制限時間・区間）、速度、加速パネルの強さ |
| `render.js` | 描画（遠近法の投影、床や棚、キャラクターや障害物） |
| `game.js` | ゲーム進行（障害物の出現、当たり判定、タイマー、HP、結果画面） |

- **ステージ1 スーパーマーケット**: 青果 → 精肉・鮮魚 → 日用品 → お菓子コーナーを抜けてレジへ
- **ステージ2 帰り道**: 一般道 → 高速道路 → 家の近所を通って、わが家へ
- **操作**: 画面のどこでも指を置いて左右にスライド（指を動かした分だけカートが動く）
- **加速ジャンプ台**: 乗るとジャンプしながら加速。ジャンプ中に次の台に乗るとさらに加速して滞空が伸びる（最大3段階）。空中では低い障害物を飛び越えられる
- **速度表示**: スーパー約280km/h、高速道路約450km/h、ジャンプ連続で最大約830km/h（表示倍率は `CartSpeedo`）
- **プレイ中の文字は最小限**: 高速操作の邪魔にならないよう、画面中央には文字を出さず、情報は上部のHUDにまとめる
- **ギリギリ回避**: 障害物すれすれで避けるとボーナス。続けるとコンボで点数アップ
- **チェックポイントモード**: 制限時間 + HP3。チェックポイントで時間が追加され、HPが1回復
- **タイムアタック**: HPなし。ぶつかるたびに +3秒。最速タイムを記録

難易度の調整は `stages.js` の `startTime` / `cpBonus`（時間）と、
`stages.js` の `CartThemes`（速度）・`CartJump`（ジャンプ台）・`CartSpeedo`（速度表示）、`game.js` の `spawnRow`（障害物の密度）で行えます。
