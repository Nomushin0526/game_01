ウインナー焼き

あそびかた

火加減（ガスコンロのつまみ）

つまみを時計回りに回すと点火、さらに回すほど強火。強いほど早く焼けますが、中が急に熱くなると蒸気で皮がパンパンになり、耐えきれないと破裂（即終了）。

水（ビーカー）

右上のビーカーをおしている間だけ注げます。目盛りは10mlごと。入れた量と「大さじ◯杯くらい」の目安が出ます（1本なら大さじ2〜3杯＝30〜45mlくらいが目安）。水があるあいだは100℃くらいの蒸し焼きで、中まで穏やかに火が通ります。焼き色は水が飛んでから。

転がす

ウインナーをタップ（または「転がす」）で90度ずつ回ります。下の面に焼き色が付くので、全面そろえよう。

お皿へ

焼き上がったと思ったら盛り付け。中まで火が通っているか・焼き色・ムラ・ジューシーさ・パンパン具合で採点。破裂寸前ほど高得点。
破裂のサイン：ふくらんで反りが強くなる → 表面がボコボコ浮き出てテカテカ → 肉汁の玉がにじむ → 細いひびが走る → ブルブル震えて「ピチッ」。
